# 001 · MVP

在 `feat/001-mvp` 完成第一版可运行的桌面应用，并合入 `master` 前用本文件验收。

## 范围

- [x] 中文 `README.md`、`AGENTS.md`、`docs/PRD.md`、本任务说明（文档与规范完备）
- [x] Tauri 2 + React + TypeScript 应用（桌面宿主与核心页面搭建完成）
- [x] 打开文件夹；列出 `.http` / `.rest` 请求树（支持递归扫描并过滤隐藏与依赖目录）
- [x] 环境下拉框；`{{变量}}` 替换；私有环境覆盖公共环境（多层级环境合并与嵌套点号解析）
- [x] Rust `reqwest` 发送；响应区显示状态码、耗时、响应头、整理后的 JSON（桌面原生发送避免 CORS）
- [x] `examples/`：httpbin 示例、`http-client.env.json`、`http-client.private.env.json.example`（示例与测试用例就绪）
- [x] `.gitignore` 忽略 `http-client.private.env.json`（避免敏感私有变量提交）
- [x] 解析器单元测试，以及扫描 / URL 校验的 Rust 测试（Vitest 与 Cargo test 均有单测覆盖）

## 不做

脚本执行、写回请求文件、账号、协作、Mock、代理配置、请求历史。

npm install
npm test

npm run build
npm run check:rust
