# 001 · MVP

在 `feat/001-mvp` 完成第一版可运行的桌面应用，并合入 `master` 前用本文件验收。

## 范围

- 中文 `README.md`、`AGENTS.md`、`docs/PRD.md`、本任务说明
- Tauri 2 + React + TypeScript 应用
- 打开文件夹；列出 `.http` / `.rest` 请求树
- 环境下拉框；`{{变量}}` 替换；私有环境覆盖公共环境
- Rust `reqwest` 发送；响应区显示状态码、耗时、响应头、整理后的 JSON
- `examples/`：httpbin 示例、`http-client.env.json`、`http-client.private.env.json.example`
- `.gitignore` 忽略 `http-client.private.env.json`
- 解析器单元测试，以及扫描 / URL 校验的 Rust 测试

## 不做

脚本执行、写回请求文件、账号、协作、Mock、代理配置、请求历史。

## 验收

| 编号 | 标准 |
| --- | --- |
| AT-01 | `examples/httpbin/*.http` 能被解析成多条请求，名称来自 `###` 后面的文字 |
| AT-02 | 注释、`< {% %}` 前置脚本、`> {% %}` 响应脚本不进入请求体 |
| AT-03 | `http-client.env.json` 的嵌套字段可按 `{{a.b}}` 替换；同一路径上 private 覆盖 public；兄弟目录的 private 不会进入另一个目录的请求 |
| AT-03b | `# @name` 和 `// @name` 会作为请求名，并优先于 `###` 标题 |
| AT-04 | 缺变量时界面标出名称，并且不发送 |
| AT-05 | 切换 `httpbin` / `local` 后，示例请求的地址分别变成 `https://httpbin.org` 和 `http://127.0.0.1:8080` |
| AT-06 | 打开文件夹后能看到子目录里的 `.http`，并跳过 `node_modules` 和 `.git` |
| AT-07 | 发送只接受 `http` 和 `https`，在 Rust 进程里发出，响应区有状态码、耗时、响应头和 JSON 正文 |
| AT-08 | 仓库里没有真实密钥、公司域名或本机绝对路径；private 环境文件被忽略 |
| AT-09 | `npm test`、`npm run typecheck`、`npm run build`、`npm run check:rust`、`npm run test:rust` 通过 |

## 验证命令

```bash
npm install
npm test
npm run typecheck
npm run build
npm run check:rust
npm run test:rust
```

桌面发送用 `npm run tauri dev` 打开 `examples/`，选「查询参数」，环境选 `httpbin`，点发送，确认状态码和 JSON 正文。
